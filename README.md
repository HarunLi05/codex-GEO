# GEO 在线方案工作台

公开仓库仅用于发布编辑器代码和通用模板。

在线使用：<https://harunli05.github.io/codex-GEO/>

## 报告保存与隐私

- 在网页里编辑的客户资料、报告正文、方案列表和历史版本，仅保存在当前浏览器中，不会上传到 GitHub 或自动发布到网站。
- 保持原有网站地址和浏览器存储键不变，更新网站不会主动删除用户已经保存的本机方案。
- 需要交付时，通过“导出客户版”或“打印 / PDF”保存到电脑，再由用户自行发送。导出会移除编辑工具和本机方案列表。
- 通过“备份全部方案”和“导入备份”迁移本机数据；备份文件应自行妥善保存。
- 当前不提供账号、云端同步或多用户权限隔离。同一浏览器配置中的其他使用者可能访问本机记录；清除站点数据会删除本机记录。
- 不要把客户报告、PDF、备份或真实客户资料加入公开仓库、模板代码或提交历史。`.gitignore` 已排除常见报告与备份路径，但不代替发布前检查。

公开网站和分支只保留通用编辑功能，原先上传的报告及内置客户专版已移除，公开分支以干净的新历史发布。旧提交直链、托管缓存或已下载副本仍可能保留此前公开的内容，不能保证撤回。

## 使用

1. 在“我的方案”新建或选择客户方案。手机端通过“我的方案”按钮打开列表。
2. **客户资料**：以五组信息填写推广对象、目标客户、优先问题、真实依据与优势、希望承接的行动。后三组提供可点选预设词，可继续补充和修改；区域、问题清单与标准目标按需展开。预设默认不选中，不代表事实已核实或服务自动包含。
3. **服务安排**：平台选择放在服务配置；“首月排期”按周明确工作与交付，“年度运营”明确全年阶段重点及每月计划、内容发布台账、监测问题、复盘安排；“工作说明”按需修改。
4. **预览与导出**：按章节查看客户版本，可返回对应栏目编辑。打印和客户版 HTML 共用 A4 排版：逐章测量，优先压缩间距，必要时适度缩放（最低90%）；超出可读范围时生成明确续页，保留所有文字并更新实际页码。

第一步的新客户资料默认为空，示例与提示仅作为占位文字；新建时主动填写的客户名称会保留。旧版本完全匹配系统示例的文字按未填写处理，实际客户资料与历史记录继续保留。可选服务目标不填时沿用报告标准目标，填写后替换，清空后恢复标准目标。

编辑自动保存在当前浏览器，无需下载后再打开。历史版本、手动留存节点及复制方案位于“更多操作”，备份和导入位于方案侧栏。

新增业务依据、承接行动和例外备注字段默认留空；业务信息以独立标签展示在报告中，不与标准段落拼成长句。服务范围、题材和承接方式仍需双方核实。核实注释保留在第1页和第4页，其他页脚仅显示客户名称、方案名与页码。

观察问题不会按业务资料自动生成：留空时仅显示待确认说明。专业性较强的业务建议主动展开问题清单，填写2—3个经客户核实术语和适用范围的具体提问。

旧版已有的本机方案、字段和历史记录保持兼容；切换步骤不会丢失编辑内容。每个方案最多保留30个版本，恢复前的内容也会留存。存储失败会明确提示；其他标签页同时修改时暂停保存，避免覆盖。

第6页末尾的服务对接说明固定为“服务对接：启动时确认服务对接人与联系方式。”，不再读取旧方案的 contact 字段；旧字段与历史资料仍保留，但不再作为可编辑输入或写入报告。内容核对安排仍独立填写。

## A4 打印

- 工作台“打印 / PDF”和导出客户版 HTML 使用相同的离线 A4 排版功能。
- PDF 设置建议：A4、纵向、缩放100%、边距无，并关闭浏览器自带页眉页脚；报告内已有独立页脚。
- 通常字量以六页模板排版。超过单页可读容量的内容按章节明确续页，不裁切文字、不用无限缩小字号硬塞六页。
- 打印只测量报告副本，不改动客户资料、方案正文及历史记录。客户版 HTML 内置的脚本仅负责离线打印排版，不读取浏览器方案库，不访问外部网络。
- “工作”“交付”“贵司配合”等旧版扁平标签会补齐中文冒号；原始历史记录不被改写。

## 开发与部署

静态网页，无需构建依赖。GitHub Pages 来源为 `main` 分支的 `/(root)`。

本地运行：`python -m http.server 8765 --bind 127.0.0.1`。

安装 Python Playwright 与 Chromium 后运行 `python tests/test_workspace.py`，验证本机保存、历史恢复、报告导出、编辑期间无网络请求，以及异常处理。另需 PyMuPDF（`fitz`）运行 `python tests/test_print_layout.py`，以真实 PDF 验证全部预设、长业务说明、手机打印、独立 HTML、续页文字完整性和实际页码。测试夹具为虚构业务信息，不含真实客户报告。

页面使用内容安全策略禁止连接远程接口；没有报告上传或自动同步功能。网站公开访问与报告在本机保存是两个独立范围。
